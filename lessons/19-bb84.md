# Lesson 19 — BB84 quantum key distribution

**Example:** [`examples/19_bb84.rs`](../examples/19_bb84.rs) ·
`cargo run --example 19_bb84`

## The idea

Every algorithm so far *computes*. BB84 instead *communicates securely*. It lets
two parties (Alice and Bob) agree on a shared secret key with a guarantee rooted
in physics rather than in a hard math problem: any eavesdropper is detectable.

The security comes from one fact you already know. A qubit measured in the
**wrong basis** gives a random result and is disturbed in the process. So an
eavesdropper who intercepts and measures the qubits — without knowing which basis
each was prepared in — inevitably corrupts a fraction of them, and Alice and Bob
can spot that corruption.

The protocol:

1. For each qubit, Alice picks a random **bit** and a random **basis** (Z or X)
   and prepares the qubit accordingly.
2. Bob measures each qubit in his own random basis.
3. They publicly announce their **bases** (never the bits) and keep only the
   positions where the bases matched — the **sifted key**.
4. They compare a handful of sifted bits to estimate the error rate. Low error ⇒
   trust the key. High error ⇒ someone tapped the line; discard it.

If nobody interferes, matched-basis positions agree perfectly (0% error). If Eve
intercepts and re-sends, she guesses the basis wrong half the time and, on those,
flips Bob's result half the time — injecting roughly a **25% error rate** on the
sifted key.

## The code

We build every preparation and measurement as a one-qubit circuit, and get all
the random choices from superposition itself:

```rust
fn prepare(bit: u8, basis: u8) -> Circuit {
    let mut c = Circuit::new(1);
    if bit == 1   { c.x(0); }   // |0> or |1>
    if basis == 1 { c.h(0); }   // Z basis or X basis
    c
}
```

The eavesdropper is modeled per qubit: Eve measures Alice's qubit in her basis
(collapsing it), then re-prepares what she saw and forwards it to Bob.

## What you'll see

```
=== No eavesdropper ===
  sifted 10 of 20 qubits
  Alice key: 1111001110
  Bob   key: 1111001110
  error rate on sifted key: 0/10 = 0.0%  (keys match: true)

=== With an eavesdropper ===
  error rate on sifted key: 2/10 = 20.0%
```

About half the qubits survive sifting (bases match ~50% of the time). Without
Eve the keys are identical; with Eve, errors appear — the tell-tale signature of
interception. (The exact percentage fluctuates around 25% run to run.)

## Try it yourself

1. Increase `n`. Does the eavesdropper's error rate settle closer to 25%?
2. What happens to the *sifted* fraction as `n` grows — and why ~50%?
3. Real BB84 follows sifting with *error correction* and *privacy amplification*
   to distil a shorter, fully secret key. Sketch why those extra steps are
   needed.

## Key takeaway

BB84 turns the measurement-disturbance principle into a security feature:
eavesdropping is not just risky, it's *detectable*. It's the foundation of
quantum cryptography and a fitting capstone to the whole tutorial — the same
qubits, gates, and measurements, aimed at a completely different goal.
